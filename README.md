# unity-study

바이브코딩(AI와 함께 코딩)으로 유니티를 배우면서, 2D 원터치 게임 하나를 itch.io 출시까지 완성하는 프로젝트입니다.

## 목표
- AI에게 일을 잘 시키는 법 익히기
- 유니티 기본기 익히기 (Scene, Prefab, 충돌, UI, 빌드)
- 게임 하나를 끝까지 완성해서 출시하기

## 환경
- Unity 6 (2D 템플릿, WebGL Build Support 포함)
- AI: Claude
- 버전 관리: Git + GitHub
