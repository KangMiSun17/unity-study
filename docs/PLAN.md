## 바이브코딩 규칙
1. 한 번에 기능 하나만 요청한다.
2. 기능 하나가 동작하면 바로 커밋한다.
3. 에러는 Console 메시지 전체를 그대로 붙여넣는다.
4. "에디터에서 할 작업도 클릭 순서대로 알려줘"를 붙인다.
5. 인스펙터 연결이 복잡하면 "코드로 처리하는 방식으로" 요청한다.
6. 막히면 화면 스크린샷을 보여준다.
7. 새 기능 아이디어는 `GAME_DESIGN.md`의 "출시 후" 목록에 적고 지금은 만들지 않는다.
